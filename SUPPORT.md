# Support and issue reporting

Report bugs and feature requests in the [DevLens issue tracker](https://github.com/aayush1234434-stack/DevLens/issues). Include the DevLens version, VS Code version, operating system, language ID, review command, expected result, and actual result. For provider failures, include the safe error message and whether local-only review still worked.

Do not post API keys, proprietary source, full prompts, or private profile/history data in an issue. A small synthetic reproduction is preferred. For a security or privacy concern, use GitHub's private vulnerability reporting if it is enabled for this repository; otherwise contact the repository owner privately before filing a public issue. The private reporting route must be verified before release.

Proposed beta support window: eight weeks from the first beta distribution, with best-effort weekly issue triage and no response-time guarantee. The maintainer should approve or revise this commitment before inviting testers. After the window, decide whether to publish a stable release, extend beta, or retire the preview.
